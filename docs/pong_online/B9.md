# B9 — ExtraTrees opcional integrado

Identificador `extra_trees`, sin destilación ni experto. Comparte el motor de B8. `ExtraTreesConfig` registra `n_estimators`, `max_depth`, `min_samples_leaf`, `n_jobs=1`, versión de scikit-learn y `encoding=nominal_missing_v1`. Defaults explícitos: 20 árboles, profundidad 4, soporte 2, scikit-learn 1.9.1. No se habilita en los protocolos obligatorios automáticamente: añadirlo a una variante antes de congelarla.

La matriz nominal congela columnas por catálogo: faltante, seguido de cada categoría observada. Falso y faltante tienen columnas distintas. No hay umbrales ordinales sobre códigos relacionales. El checkpoint conserva el estimador completo y RNG por acción; inferencia rechaza catálogo/dependencia incompatible. Las importaciones de sklearn son diferidas: los otros learners no lo requieren.

El runner offline reutiliza esta codificación y recibe `--extra-trees-config /ruta/opciones.json`. La configuración efectiva queda en identidad de unidades y complejidad. No reutilizar unidades creadas con otra configuración. El default histórico sigue siendo 20/4/2, ahora declarado en una configuración verificable.

Pruebas: reproducibilidad, faltante/falso, continuidad, evaluación sin fit, nombre ExtraTrees y rechazo de versión/codificación. Las pruebas del estimador se omiten si falta la dependencia opcional; el resto del preflight sigue disponible.
