# H2: regresión bayesiana con un árbol relacional

Implementado y validado el 2026-09-17. Avance posterior: [H3](h3.md) ya está implementado.
Este informe conserva el alcance original `m=1`; el ensemble
aditivo y backfitting corresponden a H3. No cambia el agente Atari ni introduce
actualizaciones bayesianas durante interacción con el entorno.

## Componentes

| Archivo | Responsabilidad |
|---|---|
| `bayesian_rrtl/likelihood.py` | Estadísticas `n,S,C`, marginal gaussiana completa y posterior normal de hojas |
| `bayesian_rrtl/priors.py` | Prior de estructura y reglas, varianza de hojas, inversa gamma, calibración piloto y escala fija |
| `bayesian_rrtl/proposals.py` | Grow/prune inmutables, probabilidades forward/reverse y razón MH sin truncar |
| `bayesian_rrtl/sampler.py` | Cadena con datos fijos, muestreo de hojas y ruido, draws y diagnóstico por sweep |
| `bayesian_rrtl/exact.py` | Enumeración exhaustiva, posterior estructural y matriz de transición para problemas diminutos |
| `experiments/validate_h2.py` | Validación reproducible con cuatro cadenas y un sintético con varianza desconocida |

`Tree` añade recorrido de nodos, reemplazo inmutable e identidad estructural
que excluye los valores de hojas. Las particiones de H1, las claves de relaciones
y el ruteo de faltantes se conservan.

## Decisiones implementadas

- Profundidad de raíz cero; `p_split=alpha_tree*(1+d)^(-beta_tree)` si hay
  reglas elegibles, y cero al alcanzar el límite o no poder separar observaciones.
- Prior uniforme por relación elegible y después por regla de esa relación.
  Predicados diferentes mantienen identidades diferentes aunque produzcan la
  misma partición. El prior, las propuestas y la enumeración usan ese mismo soporte.
- `grow` y `prune` se seleccionan con probabilidad fija 0,5 cada uno. Un movimiento
  imposible conserva la estructura; no se renormaliza la probabilidad del otro.
- La aceptación integra las medias de las hojas y usa likelihood, prior y ambas
  probabilidades de propuesta. Se muestrean todas las hojas después, incluso si
  se rechazó el movimiento o era imposible.
- El ruido se muestrea después de las hojas. Su conditional usa solo el número
  de observaciones y los residuos; los priors de hojas son independientes de `sigma2`.
- `sigma2 ~ IG(A,B)` significa densidad proporcional a
  `sigma2**(-A-1) * exp(-B/sigma2)`; se genera como el inverso de una gamma con
  shape `A` y scale `1/B`.
- Cada `fit` copia sus datos y reinicia una cadena. No modifica dataset, escala,
  catálogo o priors durante los sweeps y no mezcla draws de diferentes ajustes.
- La escala por defecto es identidad: límites `[-0.5,0.5]`. Para otras unidades
  se debe pasar `FixedScale` explícitamente. No se recortan respuestas ni
  predicciones; se cuenta cuántas respuestas exceden los límites.
- `calibrate_noise` opera sobre respuestas piloto ya normalizadas. Usa residuos
  lineales si el diseño tiene rango completo y grados de libertad residuales;
  en otro caso usa varianza muestral y un piso positivo documentado. Se llama
  una vez fuera del sampler; `fit` no recalibra el prior automáticamente.

Los parámetros iniciales son `alpha_tree=.95`, `beta_tree=2`, profundidad máxima
6, mínimo por hijo 1, `k=2`, `nu=3`, `lambda=.01`, 500 sweeps de burn-in y 1000
retenidos. Son valores de desarrollo; `lambda=.01` no se presenta como una
calibración de Atari. `leaf_variance(k,m)` incluye la fórmula general para H3,
pero el sampler de este hito fija `m=1`.

## Uso

Desde la raíz del repo, el entorno completo de H0 ya incluye NumPy y SciPy.
También se puede instalar `requirements-bayesian.txt` en un entorno limpio
para usar H1/H2 y sus pruebas sin Atari, OpenCV ni Graphviz.

```python
from collections import namedtuple
import numpy as np
from bayesian_rrtl import RelationalEncoder
from bayesian_rrtl.priors import FixedScale, TreePrior, calibrate_noise
from bayesian_rrtl.sampler import SingleTreeSampler

Fact = namedtuple("Fact", "type value name obj1 obj2 obj3", defaults=[None, None])
states = [
    [Fact("comparative", "less", "x", "player_t", "ball_t")],
    [Fact("comparative", "same", "x", "player_t", "ball_t")],
    [Fact("comparative", "more", "x", "player_t", "ball_t")],
    [],
]
y = np.array([-0.3, 0.0, 0.3, 0.1])
encoder = RelationalEncoder.from_states(states)
x = encoder.transform(states)
scale = FixedScale(-0.5, 0.5)
# En experimentos, usar un piloto de entrenamiento separado para calibrar.
calibration = calibrate_noise(scale.normalize(y))
sampler = SingleTreeSampler(
    tree_prior=TreePrior(max_depth=2), noise_prior=calibration.prior, scale=scale
)
posterior = sampler.fit(x, y, np.random.default_rng(17), burn_in=500, draws=1000)
q_mean = posterior.predict_mean(x)                     # [n_states]
latent = posterior.predict_latent_draws(x)             # [n_draws, n_states]
observed = posterior.predict_observation_draws(x, np.random.default_rng(18))
print(posterior.diagnostics())
```

`q_mean` es solo el nombre de una predicción supervisada en este ejemplo; no se
han construido targets TD ni aprendido una política. Las predicciones regresan
a unidades originales. `trees` y `sigma2` están en unidades normalizadas, y el
resultado conserva escala, priors, `k`, hash del catálogo y del dataset, burn-in
y traza de diagnósticos. El predictor observacional añade ruido residual; el
predictor latente no lo añade. La media promedia draws de un único árbol.

`fixed_sigma2` en `fit` permite validar con una varianza conocida **normalizada**.
Al omitirlo, se muestrea el ruido. No existe todavía serialización versionada ni
reanudación de este sampler; la persistencia del agente completo es parte de H5.

## Reproducir la validación

```bash
.venv/bin/python -m pytest -q
.venv/bin/python -m experiments.validate_h2 --output results/h2_validation
```

El directorio debe ser nuevo. Para repetir, usar otro `--output`. El experimento
produce `validation.json`, `encoder.json`, `structures.json` y
`exact_reference.npz`, con la posterior exacta, el kernel completo y frecuencias
por cadena. No requiere red ni Atari. La enumeración tiene un límite de tamaño
para evitar usarla accidentalmente con datasets grandes.

Resultados registrados en [validation_h2.json](validation_h2.json):

- 50 pruebas aprobadas: 30 anteriores y 20 nuevas de H2.
- Marginal comparada con cuadratura y una normal multivariante independiente.
- Momentos conjugados con tolerancias de error Monte Carlo.
- Caso raíz con ruido desconocido contrastado con cuadratura de su posterior
  conjunta, usando errores estándar por medias de bloques.
- Prior normalizado sobre 20 estructuras; filas del kernel suman uno.
- Error máximo de balance detallado: `6.94e-18`.
- Error máximo de estacionariedad: `1.39e-17`.
- Cuatro cadenas: 2000 sweeps de burn-in y 20000 draws cada una.
- Distancia de variación total entre frecuencias y posterior: `0.0156–0.0172`.
- Mayor error de frecuencia de una estructura: `0.00784`.
- Sintético de tres categorías con ruido desconocido: RMSE sobre la señal
  `0.00522` (una ejecución de comprobación; no es una campaña de cobertura).

Las tolerancias de frecuencias consideran autocorrelación mediante una cota
espectral del kernel exacto. La referencia exhaustiva es para estructura con
varianza fija, no para la posterior completa de un MDP ni un ensemble. Los
resultados muestran que este kernel pequeño se comporta como se especificó;
no establecen tiempos de mezcla para árboles o datasets grandes.
